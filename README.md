# 價格牌產生器

映象音響門市自助價格牌產生工具，單一 HTML 檔案、免安裝、可直接離線使用，也部署在 GitHub Pages 供線上使用。

## 線上使用

https://michelle776.github.io/price-tag-generator/

## 本機使用

直接用瀏覽器開啟 `index.html` 即可，不需要安裝或建置任何東西。

## 版型

- **商品組合卡**（15×10cm）：多品牌 Logo + 商品清單 + 原價／特價
- **規格價目表**（11×15cm）：單一品牌 + 多列規格與價格，適合同系列多尺寸／型號
- **單品比價卡**（7×4cm）：置中文字 + 原價／特價對比，適合單一商品陳列卡
- **大巨蛋門市卡**（12×9.5cm、7×4cm 或 A4）：套用遠東 Garden City（大巨蛋門市）燙金葉子底圖，切換背景會自動套用對應的範例文字與版面（置中／靠左、售價特價排列方式皆不同）；12×9.5 版面在價格下方多一行備註（預設為「產品尺寸」）；A4 版面為規格價目表式，可列多列「名稱/規格 + 價格」（如同款多尺寸商品），隔行底色可自訂，整張卡片以 A4 滿版（無邊界）列印

## 主要功能

- 一次管理多張價格牌，各自設定尺寸與列印份數，依序自動排版成 A4 頁面，畫面所見即所印，可直接「列印／存成 PDF」
- 品牌 Logo 下拉選單（含上傳自訂圖片取代內建 Logo）
- 整體文字大小／行距調整，另外每一行文字（標題、項目、價格列等）都可以用「單行微調」工具個別調整字體大小與上下左右位置
- 內容會自動存在瀏覽器 localStorage，重新整理頁面不會遺失

## 檔案結構

```
index.html          全部程式碼（HTML / CSS / JS 單一檔案）
logos/               品牌 Logo 圖片
templates/           大巨蛋門市卡背景底圖（12×9.5、12×8、7×4、A4）
```

## 部署

推送到 GitHub `master` 分支後，GitHub Pages 會自動重新建置線上版本，通常 1 分鐘內完成。
