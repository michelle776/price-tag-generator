# 價格牌產生器

映象音響門市自助價格牌產生工具，單一 HTML 檔案、免安裝、可直接離線使用，也部署在 GitHub Pages 供線上使用。

## 線上使用

https://michelle776.github.io/price-tag-generator/

## 本機使用

直接用瀏覽器開啟 `index.html` 即可，不需要安裝或建置任何東西。

## 版型

- **天母SOGO**（一個分頁，內含三種版面，在「天母SOGO 版面」下拉切換）：
  - **商品組合卡**（15×10cm）：多品牌 Logo + 商品清單 + 原價／特價
  - **規格價目表**（10.8×15cm）：單一品牌 + 多列規格與價格，適合同系列多尺寸／型號
  - **小張電視價格表**（10×7cm）：品牌 Logo + 系列名稱／特色 + 型號，左下尺寸小字、右下大字價格；可另填特價（原價縮小在上、特價以強調色在下）。列印時頁邊縮為 0.4cm 並置中，一張 A4 排 2×4＝8 張；按「新增卡片補滿A4」會在清單新增卡片（複製目前這張）補到 8 張，再逐張改成不同商品
- **台茂價格卡**（7.5×4cm）：置中文字 + 原價／特價對比，適合單一商品陳列卡
- **大巨蛋門市卡**（12×9.5cm、7×4cm 或 A4）：套用遠東 Garden City（大巨蛋門市）燙金葉子底圖，切換背景會自動套用對應的範例文字與版面（置中／靠左、售價特價排列方式皆不同）；12×9.5 版面在價格下方多一行備註（預設為「產品尺寸」）；A4 版面為規格價目表式，可列多列「名稱/規格 + 價格」（如同款多尺寸商品），隔行底色可自訂，整張卡片以 A4 滿版（無邊界）列印
- **台茂特賣會**（10.5×14.85cm，A4 四分之一，一張 A4 無邊界拼 4 張）：深藍外框＋米色內板的單品特賣卡（品牌 Logo／商品名稱／型號／商品介紹／原價／新品特價／限量幾台以右下紅色圓圈章呈現）。支援 **Excel 一鍵批次匯入**：先「下載範本 Excel」，依欄位順序（品牌｜商品名稱｜型號｜商品介紹｜原價｜新品特價｜限量）填好，「商品介紹」在同一格用 Alt+Enter 換行即每行變一個「・」項目；匯入時會清空並取代整份清單，每張商品變成一張卡片，再逐一點選左側清單確認／修改（自動存檔）。品牌欄填名稱文字（如 LG、Samsung、鐵三角）即自動對應內建 Logo

## 主要功能

- 一次管理多張價格牌，各自設定尺寸與列印份數，依序自動排版成 A4 頁面，畫面所見即所印，可直接「列印／存成 PDF」
- 尺寸剛好能整除 A4 的卡片（例如台茂 10.5×14.85cm）會以無邊界方式一頁拼多張
- 標籤間距（張與張之間留白）可調，預設 0.2cm；可勾選「顯示裁切線」列印淡灰虛線裁切輔助
- 品牌 Logo 下拉選單（含上傳自訂圖片取代內建 Logo）
- 整體文字大小／行距調整，另外每一行文字（標題、項目、價格列等）都可以用「單行微調」工具個別調整字體大小與上下左右位置
- 台茂特賣會版型可用 Excel 一鍵批次匯入整份商品清單（見下方說明）
- 內容會自動存在瀏覽器 localStorage，重新整理頁面不會遺失
- 「儲存清單（下載檔案）」把整份清單（含上傳的 Logo）存成 .json 檔，可備份、換電腦或傳給其他門市；「開啟清單檔案」選該檔即可還原（會取代目前清單）

## 台茂特賣會 Excel 批次匯入

1. 切到「台茂特賣會」版型，點「↓ 下載範本 Excel」取得 `台茂特賣會_匯入範本.xlsx`
2. 依欄位順序填寫（第一列是表頭，會自動略過）：

   | 欄位 | 說明 |
   | --- | --- |
   | 品牌 | 填名稱文字（LG、Samsung、鐵三角…），自動對應內建 Logo；對不到就留空、之後在該張卡片手動選 |
   | 商品名稱 | 可用 `**文字**` 加粗 |
   | 型號 | |
   | 商品介紹 | **同一格用 Alt+Enter 換行**，每行變一個「・」項目（也支援「、」「；」分隔） |
   | 原價 | 只填數字即可，會自動加千分位 |
   | 新品特價 | 同上，數字會套用強調色 |
   | 限量 | 選填，有填才會顯示右下紅色圓圈章 |

3. 回工具點「選擇填好的 Excel 檔匯入」→ 確認後**會清空並取代目前整份清單**，每列商品變成一張卡片
4. 逐一點選左側「價格牌清單」確認／微調各張內容（自動存檔），再「列印／存成 PDF」

## 檔案結構

```
index.html           全部程式碼（HTML / CSS / JS 單一檔案）
logos/               品牌 Logo 圖片
templates/           大巨蛋門市卡背景底圖（12×9.5、12×8、7×4、A4）
vendor/              第三方函式庫（xlsx.full.min.js：台茂特賣會 Excel 匯入 / 範本產生用）
tests/               自動測試（node --test "tests/*.test.js"）
```

## 部署

推送到 GitHub `master` 分支後，GitHub Pages 會自動重新建置線上版本，通常 1 分鐘內完成。
（`master` 就是 Pages 來源分支，直接推即可；專案根目錄的參考底圖 / 截圖不納入版控。）

## 自動測試

改完程式、推送之前可以先跑一次（需安裝 Node.js 18 以上，不需要 `npm install`）：

```
node --test "tests/*.test.js"
```

涵蓋：開啟網頁時舊存檔的轉換（`loadDeck`）、台茂 Excel 批次匯入（品牌比對、介紹拆行、價格清理、範本匯回）、
A4 列印排版（`buildPages`：一般卡換行換頁、台茂 2×2 無邊界拼版）。
測試透過 `index.html` 最後的 `window.__PTG_TEST__` hook 取得內部函式；一般瀏覽器不會觸發它，請勿刪除。
